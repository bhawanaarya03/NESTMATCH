# File: `listings.html`
**GitHub Link:** [listings.html](https://github.com/bhawanaarya03/NESTMATCH/blob/main/listings.html)
## Purpose
The `listings.html` file displays available PG accommodations and allows users to search, filter, sort, and request visits to properties according to their preferences.

## Contents

- **Page Header:** Displays an introduction to the PG search page and encourages users to find suitable accommodation.
- **Search Bar:** Allows users to search for PGs by name, area, or city.
- **Area Filter:** Enables users to narrow down results by location.
- **Monthly Budget Filter:** Allows users to specify minimum and maximum rent.
- **Accommodation Filter:** Provides options for Girls, Boys, and Co-living PGs.
- **Room Type Filter:** Allows users to select Single, Double, or Triple rooms.
- **Facility Filter:** Helps users search for essential facilities such as Wi-Fi, meals, AC, laundry, and security.
- **Sorting Options:** Allows users to sort results by recommended order, rent (low to high or high to low), or rating.
- **PG Listing Cards:** Displays each property's image, name, location, description, accommodation type, room type, distance, rating, facilities, and monthly rent.
- **Visit Request Form:** Allows users to select a preferred visit date and submit a visit request for a PG.
- **Empty Results Message:** Displays a helpful message when no properties match the selected search criteria.

## Role in NestMatch
This page helps users find suitable PG accommodations based on their budget, room preferences, location, and required facilities. It uses Flask's Jinja2 template syntax to display property data dynamically and connect search, filtering, sorting, and visit-request forms to the backend routes.
