
**GitHub Link:** [style.css]

**Purpose:**  
The [`style.css'] file defines the visual appearance and layout of the NestMatch web application.

**Contents:**
- **Color scheme:** Uses a beige, cream, brown, and white palette.
- **Typography:** Defines fonts, text sizes, and font styles.
- **Layout and styling:** Styles the navigation bar, login and registration forms, PG listing cards, filters, buttons, and dashboard.
- **Responsive design:** Uses CSS media queries to adapt the website layout to different screen sizes.
- **Visual effects:** Adds hover effects, borders, shadows, spacing, and status indicators.

**Role in NestMatch:**  
This file separates the website's presentation from its application logic, making the interface easier to maintain and customize.
